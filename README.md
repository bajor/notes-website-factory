# Algo for Dummies

For every algorithm/data structure, include one intentionally simple, ugly real-life example that can be understood immediately from a phone screen.

Examples: stack → plates/barbell plates at the gym; recursion → Tower of Hanoi.

Also include a visual dry run: show the algorithm step by step with simple hand-drawn sketches/annotations made for iPad use, including lasso-style highlighting/moving of elements where it helps explain state changes.
